# Changelog

## 1.18.0 beta 1

- Add `npm run repair:check` for manually triggered repair reviews. Collect a private, sanitized diagnostic snapshot; compare source and runtime versions; group failures without duplicate counts; and flag stale or incomplete evidence.
- Clearly distinguish historical tab observations from live agent status. Missing or invalid reports fail visibly.
- Keep software repair and installation manual: the check never edits source, controls chats, reloads the extension or schedules maintenance.

## 1.17.2 beta 1

- Recover from ChatGPT’s “Error in message stream” alert using the same guarded, single reload as delivery timeouts. Never click Retry or resend the interrupted prompt.
- Detect a stream error that appears after a partial reply has already entered the missing-Logic-flag wait. Preserve manual typing and pauses.
- Verify the saved user message after reload, then monitor ongoing work or process the completed Logic flag. Another error pauses automation and reports it without another reload.
- Record message-stream recovery as a distinct private diagnostic category. Restart the LAN helper to retain the new category.

## 1.17.1 beta 1

- Recover handoff confirmation when ChatGPT saves a new conversation while sender verification is in progress. Retry only an explicitly rejected confirmation, with fresh chat-ownership checks and at most three attempts; never resend the startup prompt or retry an uncertain result.
- Keep different saved chats, projects and replaced documents blocked.
- Fix automatic reconnection rejecting the page identifiers generated by earlier versions. New controllers use UUIDs; existing identifiers remain supported.
- Distinguish handoff trust failures, reconnection trust failures and missing final Logic flags in private diagnostics. Record confirmation retries without message text. Restart the LAN helper to retain the new diagnostic fields.

## 1.17.0 beta 1

- Reattach Threadlamp controls to already-open ChatGPT tabs after an extension reload or update, without refreshing the conversation. Shut down old timers, message listeners and controls before replacing them.
- Preserve saved queues and drafts. Reattached tabs pause automation and enabled heartbeats for review; no prompt or interrupted send is replayed. Use Resume Logic Mode after inspecting the chat and its run settings, and resume its schedule separately when ready.
- Require one safe page refresh for tabs still running versions before 1.17.0. Loading or discarded tabs may need to finish loading or be opened before controls are available.
- Avoid retrying popup commands after a missing reply, since delivery may already have succeeded.

## 1.16.4 beta 1

- Keep queues attached during the new-chat transition from a project landing page through a temporary chat ID to its saved conversation. Preserve queues stored by earlier versions.
- Verify the exact active browser document when sender URL metadata lags behind navigation; different chats, projects and replaced documents remain blocked.
- Retry only the initial queue read if the page changes while it is loading. Queue writes and sends are never automatically retried.
- Include the queue operation and verification failure category in private diagnostics without message text or URLs. Restart the LAN helper to retain these new diagnostic fields in its local report.

## 1.16.3 beta 1

- Show agents waiting on a WAIT timer or external operation with a purple bullet. Agents waiting for user input remain yellow.

## 1.16.2 beta 1

- Show sleeping agents with a light blue bullet. Running agents remain green and paused agents remain blue.

## 1.16.1 beta 1

- Remove obsolete OpenRouter error messages from agent summaries while retaining saved summaries and genuine Logic SUMMARY notices.
- Show the shared OpenRouter rate-limit cooldown beside every Rewrite control. Messages now describe draft rewriting and when to click Rewrite again; completed chat outputs do not retry OpenRouter.

## 1.16.0 beta 1

- Read dashboard summaries from a 600-character `LOGIC:SUMMARY` line before the final control flag; completed responses no longer trigger OpenRouter requests.
- Add explicit Rewrite and Undo controls to dashboard message editors using the existing OpenRouter free router settings. Protect edited drafts and changed agent selections from late results.
- Color agent bullets green for running, yellow for input, orange for errors, red for stopped, blue for paused and gray for unavailable.
- Save queued messages across reloads and browser restarts, transfer them only through verified project handoffs, and persist dequeue before Send to prevent replay after uncertain delivery. Stop preserves the queue; Remove and Clear queue discard entries.
- Record rewrite failure metadata without draft text. Reload the extension and chat tabs when safe, restart the LAN helper, and start Logic Mode with the updated instructions in existing chats. Older versions did not persist queues: preserve any pending entries before this first upgrade.

## 1.9.6 beta 1

First public beta of Threadlamp by Phosphoros Research.

- Follow-up loops with message limits and Pause/Stop controls.
- Logic Mode with continue, wait, input-request, and idle states.
- A prompt queue for adding instructions to the next automatic turn.
- A dashboard for conversation status, replies, and schedules.
- Per-conversation heartbeats and project conversation rollover.
- Optional Home Assistant notifications and local server event delivery.
- Encrypted export and import of supported settings.
- Compact dashboard layout with an accessible queue action at intermediate heights.

coverage, and the [README](README.md#beta-limitations) for beta limitations.
