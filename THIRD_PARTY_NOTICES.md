# Third-party notices

Threadlamp uses browser APIs and bundles no third-party runtime libraries, SDKs,
fonts, or media. Tests use Node.js built-in modules; packaging scripts use the
Python standard library. The application icons are original geometric artwork
covered by the [branding terms](BRANDING.md).

The [MPL-2.0 license text](LICENSE) is provided by
[Mozilla](https://www.mozilla.org/MPL/2.0/).

Dashboard design references include the following guidance. No code or assets
from these sites are bundled:

- [Carbon tabs](https://www.carbondesignsystem.com/building-blocks/core/components/tabs/guidelines)
- [Carbon disclosures](https://www.carbondesignsystem.com/building-blocks/core/patterns/disclosures)
- [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)
