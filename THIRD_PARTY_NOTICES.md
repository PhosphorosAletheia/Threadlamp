# Third-party notices and provenance

No third-party runtime library, vendored package, remote font, media file or
bundled SDK was identified in this beta snapshot. Runtime code uses browser APIs;
tests use Node.js built-in modules. Python packaging scripts use its standard library.
The application icons are original geometric artwork prepared for this release.

The MPL-2.0 license text comes from Mozilla's official plain-text distribution:
https://www.mozilla.org/MPL/2.0/

This is a source inspection statement, not proof of ownership or a copyright
clearance. Contributors must disclose any outside source incorporated into their
work so its notices and compatibility can be reviewed before distribution.

Earlier dashboard design documentation cited the public Carbon Design System
tabs/disclosure guidance and WAI-ARIA tab keyboard behavior as design references;
no library code or assets from those sites are bundled here.
