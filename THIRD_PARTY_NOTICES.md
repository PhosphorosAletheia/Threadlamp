# Third-party notices

The Chrome extension uses browser APIs and bundles no third-party runtime
libraries, SDKs, fonts, or media. The optional LAN helper installs the pinned
[ws](https://github.com/websockets/ws) dependency under the MIT license. Tests use
Node.js built-ins and ws; packaging scripts use the Python standard library. The application icons are original geometric artwork
covered by the [branding terms](BRANDING.md).
